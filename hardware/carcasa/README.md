# Carcasas impresas en PLA (design files)

Archivos de la carcasa del nodo sensor y del gateway, para impresión 3D.

| Archivo | Qué es |
|---|---|
| `carcasa-sensor.stl` | Cuerpo de la carcasa del nodo sensor |
| `tapa-sensor.stl` | Tapa del nodo sensor |
| `carcasa-gateway.stl` | Cuerpo de la carcasa del gateway/visualizador |
| `tapa-gateway.stl` | Tapa del gateway |
| `sensor.3mf.zip` | Proyecto 3MF del nodo (laminado/orientación de impresión) |

**Formato:** solo STL + 3MF (archivos para imprimir). No se dispone del CAD
editable original. Para HardwareX, el STL es un design file válido; el CAD
editable se documentará si se rehace el modelo.

**Nota IP:** la carcasa PLA impresa no tiene una clasificación IP certificada;
está pensada para ambiente controlado / interior. Para exteriores o zonas con
polvo/humedad se recomienda rediseñar con sellos apuntando a IP54/IP65.
